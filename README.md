# Toggle Text (ON / OFF)

A simple web application to practice DOM manipulation and event handling. This project toggles a heading text between **"ON"** and **"OFF"** using vanilla JavaScript.

## 🎯 Project Goals
- Practice **Basic HTML Structure**.
- Implement **Flexbox** for centering content (`justify-content`, `align-items`).
- Use **JavaScript** to handle click events and modify DOM elements.
- Ensure **Responsive Design** without external frameworks.

## ⚙️ How It Works
1. The page loads with the status set to **OFF**.
2. Clicking the **Toggle** button switches the text to **ON**.
3. Clicking again switches it back to **OFF**.

## 🛠️ Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Flexbox, Responsive design)
- **JavaScript** (Event listeners, DOM manipulation)

## 🚀 How to Run
1. Clone or download the files.
2. Open `index.html` in your browser.
